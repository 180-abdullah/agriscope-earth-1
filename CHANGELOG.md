# Changelog

## 0.2.0 — Scientific workbench release

- Rebuilt the Streamlit interface around Guided and Research modes.
- Added global place search and a dependable Leaflet target map.
- Added an original God’s-Eye-inspired deck.gl operations view with a WebGL fallback.
- Added keyless Sentinel-2 L2A scene search and bounded clear-pixel NDVI/NDMI processing through Element 84 Earth Search.
- Added acquisition identifiers, timestamps, quality fractions, sampled area, data-status labels, and source terms to research records.
- Added land-change CSV import with schema validation and evidence confirmation.
- Added JSON, CSV, GeoJSON, Markdown, and session-comparison exports.
- Corrected GloFAS ensemble terminology and strengthened user-supplied/default evidence labeling.
- Added scientific-integrity documentation, validation boundaries, a study-protocol checklist, and external-validation roadmap.

## 0.1.0 — Initial global research demonstrator

- Added six Python mission engines, FastAPI endpoints, tests, and the first Streamlit console.
